# Roteirizador Logístico com Google Maps e Streamlit
Este projeto é uma aplicação web simples para calcular a melhor rota de visitas entre uma origem e múltiplos destinos, utilizando:

* Google Maps API para distâncias reais por via

* OR-Tools para resolver o problema do caixeiro viajante (TSP)

* Streamlit para a interface web

* Folium para exibir o mapa com as rotas

Solução para quem deseja otimizar entregas, coletas ou qualquer processo logístico com múltiplos pontos.

---

## Como usar
A aplicação está disponível em:

[Aplicativo de Roteirização](https://app-roteirizacao-mathezzz.streamlit.app/)

### Passos:
1. Acesse o site.

2. Insira a coordenada de origem no formato lat, lon (ex: -23.5505, -46.6333).

3. Insira as coordenadas de destino, uma por linha ou separadas por ; (ex: -23.5510, -46.6400; -23.5600, -46.6200).

4. Clique em "Calcular rota".

5. Veja a ordem otimizada e a rota exibida no mapa.

Você pode limpar e recalcular quantas vezes quiser.
